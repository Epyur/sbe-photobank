# LogicTEAM.Фотобанк (sbe-photobank)

Внутренний корпоративный сток-фотобанк: единое хранилище фото и видео с умным поиском.

## Возможности

- **Хранение**: фото, видео и RAW-файлы загружаются в защищённое облачное хранилище (S3);
  для изображений автоматически создаются миниатюры, для видео/RAW обложку прикладывает
  пользователь.
- **Организация**: папки/альбомы (дерево), теги, свои поля метаданных, настраиваемые
  администратором.
- **ИИ-описание**: при загрузке укажите, что на кадре — плагин сам составит расширенное
  описание, теги и категорию для последующего поиска.
- **Умный поиск**: свободный ввод фразы; при необходимости система сама расширит запрос
  (подбор тегов), чтобы найти нужное даже по приблизительному описанию.
- **Права доступа**: роли (просмотр, комментарии, редактирование, администрирование);
  по умолчанию всё закрыто. Доступ назначается на папки (по почте или группам) и
  наследуется вниз по дереву; отдельный файл можно скрыть или показать точечно.
- **Совместная работа**: комментарии, лайки, избранное, недавно просмотренные, счётчик
  скачиваний.
- **Переиспользование**: кнопка «Ссылка» даёт временную публичную ссылку на файл — её
  можно вставить в письмо, документ или презентацию.

## Установка

Плагин устанавливается через ЦУП СБЕ (SBE Apstore) — раздел «Магазин». После установки
откройте из раздела «Установленные». Для работы нужны:

- плагин **ЦУП СБЕ ПМиПИР** (sbe-apstore) — авторизация и доступ к серверу;
- плагин **SBE LLM Center** (sbe-llm) — для ИИ-описания и умного поиска (необязательно:
  без него загрузка и поиск работают вручную);
- доступ, выданный администратором фотобанка (по умолчанию закрыто).
